## About the App

Media Estimator is a macOS app for media managers, DITs, and production management teams to plan and calculate their film and television production's storage requirements. Users can calculate camera media card allotments based on a number of professional camera and codec choices as well as estimate media management offload times based on the speeds of your backup shuttle medium.

---
## Features

- Project Based Organization
- Calculations for weekly totals or per episode totals for TV. 
- Custom "Shoot Day" types to determine quotas depending on content shot. ie: Reality, Interview, B-Roll  
- Estimate Media Management needs based on type of storage availabe: Hard Drive, SSD, RAID Storage, NAS (Network Attached Storage).
- Estimate Media Management needs based on if production requires single, dual, or tripple media copies.
- Estimate Avid NEXIS storage requirements based on standard proxy workflow codecs: DNxHR LB/SQ, DNx36, ProRes Proxy, ProRes LT, H.264, new Avid 2025 proxy workflow (DNxHR LB + H.264).
- Estimate LTO storage needs based tape genertaion production is using: LTO 6, 7, 8, and 9 supported.
- Estimate DIT/Media Manager Offload times based on types of camera card media and speed of archival hardware. 
- Account for if production workflow allows multiple days of media to co-exist on the same back up drives, or if requirements are single day per media.
- Pre-defined database of media codecs, speeds, and storage requirements for many professional and semi-professional workflows.
- Print friendly summary page of Daily, Weekly, or Episode totals; series/feature totals; server storage totals for Master and Proxy workflows; and a full breakdown of the type and count of camera media cards and archival media needed.
